5. EVERY OBJECTIVE MUST BELONG TO ONE CYCLE
==================================================

An Objective MUST be attached to exactly ONE OKR Cycle.

An Objective cannot be valid for approval or execution
without a Cycle.

Use real Phase-2 Cycle data.

Do not duplicate Cycle names as arbitrary text.

The user should select from accessible/appropriate Cycles.

==================================================
6. OBJECTIVE DATES MUST FIT INSIDE THE CYCLE
==================================================

Every Objective must have:

- start date
- end date

Rules:

Objective end date > Objective start date

AND

Objective start date >= Cycle start date

AND

Objective end date <= Cycle end date

The Objective may cover a shorter period than the Cycle.

It may NOT extend outside the Cycle.

Example:

Cycle:
2026-01-01 → 2026-03-31

Allowed Objective:
2026-01-15 → 2026-03-15

Invalid Objective:
2025-12-20 → 2026-03-15

Invalid Objective:
2026-02-01 → 2026-04-15

Provide clear Arabic validation messages.

Do not implement multiple co-owners.

- organizational scope

10. KEY RESULTS — CORE RULE
==================================================

Every Objective MUST have at least ONE Key Result.

An Objective may contain multiple Key Results.

Do NOT allow submission for review with zero Key Results.

Key Results are NOT standalone top-level records in the user experience.

They belong to an Objective.

The Objective and its Key Results are treated as one connected package.

The system must treat:

Objective
+

- editing
- review
- approval
- display

Do not create a separate independent approval lifecycle for every Key Result.

Approval of the Objective later means approval of its attached Key Results.

==================================================
12. KEY RESULT — PROGRESS SOURCE
==================================================

Each Key Result must have exactly ONE progress source.

Allowed sources:

1. قياس مباشر
2. أهداف داعمة

Do NOT allow both simultaneously.

Do NOT allow undefined source once the Objective is ready
for review.

This is a critical business rule.

Do not calculate progress percentage in Phase 3.
