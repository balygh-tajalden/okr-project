# نظام إدارة الأهداف المؤسسية OKR

نظام متكامل لإدارة الأهداف والنتائج الرئيسية وفق منهجية OKR في البيئات المؤسسية والحكومية، بدعم كامل للغة العربية واتجاه RTL.

## الإمكانيات

- **إدارة الهيكل التنظيمي**: إدارات وأقسام وفرق بهيكل هرمي متعدد المستويات مع سجل تنظيمي تاريخي للمستخدمين.
- **المستخدمون والأدوار**: إدارة حسابات المستخدمين مع تعدد الأدوار وصلاحيات دقيقة قابلة للتخصيص.
- **دورات OKR**: دورات تخطيط (شهرية/ربعية/سنوية) بدورة حياة صارمة (مسودة ← نشطة ← مكتملة).
- **الأهداف والنتائج الرئيسية**: أهداف مؤسسية وتنظيمية وفردية مع نتائج رئيسية قابلة للقياس (عددي أو إنجاز/عدم إنجاز) وتسلسل هرمي (أهداف داعمة).
- **المراجعات والاعتمادات**: مسار موافقات متعدد المستويات مع سجل مراجعة كامل.
- **تحديثات الإنجاز**: طلبات تحديث دورية بقيّم فعلية تُعتمد من المراجع، مع مؤشرات أداء (متقدم/على المسار/متأخر/متعطل).
- **التنبيهات**: تنبيهات آلية للتأخر في التحديث وتعطل الأداء، مع إشعارات مقروءة/غير مقروءة.
- **لوحة المعلومات والتقارير**: تحليلات ورسوم بيانية حسب النطاق التنظيمي، وتقارير قابلة للتصدير CSV والطباعة.
- **البحث والتصفية**: بحث موحد في الأهداف حسب الحالة والنوع والأداء.

## التقنيات

- Next.js (App Router) + TypeScript
- React + Tailwind CSS + shadcn/ui
- Zustand لإدارة الحالة (تخزين محلي دائم)
- Recharts للرسوم البيانية

## التشغيل

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# البناء للإنتاج
npm run build
```

ثم افتح المتصفح على: http://localhost:3000

## ملاحظة معمارية

هذا نموذج أولي (Prototype) لغرض المناقشة الأكاديمية: تُدار البيانات في مخازن محلية (localStorage) عبر Zustand دون خادم خلفي، مع فصل طبقات الخدمات بحيث يمكن استبدالها بنداءات API فعلية دون تغيير الواجهات.
